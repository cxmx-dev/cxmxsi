WinDefAddExeExclusion

A small, portable Windows 98-style app for adding or removing individual .exe files from the Windows Defender exclusion list. Made for your own freshly built programs (PyInstaller, cargo, etc.) that Defender keeps flagging.

Read this first

  • The tool is unsigned. It is a one-file PyInstaller build with no code-signing certificate.
  • It lowers Windows Defender protection. Every exclusion tells Defender to stop scanning that file, even if it is later replaced or infected. It needs Administrator.
  • Antivirus and SmartScreen may flag or quarantine it. That is common for unsigned PyInstaller apps, but you should still judge it for yourself.
  • Exclude only specific .exe files you built or fully trust. Never exclude folders or drives. Remove exclusions when you no longer need them.
  • You can rebuild it from source. The kit includes WinDefAddExeExclusion.py, the manifest, and CreateWinDefAddExeExclusion.ps1, which builds your own copy with PyInstaller.
